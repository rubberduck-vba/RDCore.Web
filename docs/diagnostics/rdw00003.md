# RDW00003: Member not round-tripped

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDW` (RDCore.Web) &nbsp;·&nbsp; **Raised by:** `MemberNotRoundTrippedAnalyzer`

An action's body or its returned value is an object of a class of the project, and a member of that class does not come back as it went out through JSON.

A JSON object of a class has its `Public` variables and its `Public` properties whose `Property Get` takes no argument. A key of a JSON object
gives a value to a `Public` variable, or to a `Property Let` or `Property Set` that takes only the value ([JSON values](../specs/rdweb.8.0.json-values.md)).
A client that sends back the object it was sent does not give the action the object it returned when:

- a property has a `Property Get` and no `Property Let` or `Set`: it is written out, and its key is skipped when the object comes back;
- a member is declared `As Object` or `As Variant`: an object it holds comes back as a `Scripting.Dictionary`.

It is reported once at the parameter the body binds, and once at the name of an action that is a `Function` returning an object. The message names
each such member as `Class.Member`. The classes are the declared one and each class that a member of their JSON objects is declared as, at any
depth.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A read-only property.|`Public Property Get Total() As Currency` in the class `Order` that `'@HttpPost` `Public Function Place(ByVal order As Order) As Order` takes and returns.|Add a `Property Let`, or leave it: the client's value is ignored, and the action computes its own.|
|A member that holds any object.|`Public Customer As Object` in `Order`.|Declare it as the class it holds, `As Customer`.|
|A member that holds any value.|`Public Tags As Variant` in `Order`, given an object.|Declare it as the type it holds. A `Variant` that holds a value or an array comes back as that value or array.|
