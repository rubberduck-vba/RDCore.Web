# Documentation de RDCore.Web
<sup>_This document is available in [English](index.html)_</sup>

---

**RDCore.Web** est le cadriciel web de [RDCore](https://rubberduck-vba.github.io/RDCore/index.fr.html). Il sert les modules de classe d'un projet RD-VBA au moyen d'ASP.NET Core. Des annotations Rubberduck comme `'@Controller`, `'@HttpGet` et `'@HttpPost` décrivent les points de terminaison, et l'interface peut être toute application Node.js.

Le code source, son état et la façon de le construire se trouvent dans le [dépôt RDCore.Web](https://github.com/rubberduck-vba/RDCore.Web).

## Diagnostics

RDCore.Web émet ses propres diagnostics, sous le préfixe `RDW`. Chacun a une page dans [Diagnostics](diagnostics/rdw00001.md), que le lien du diagnostic dans l'éditeur ouvre.
